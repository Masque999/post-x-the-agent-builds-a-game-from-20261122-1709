Ghost Catcher — a tiny browser game built from one prompt by an AI agent: a cute ghost catches falling stars. Move with arrow keys or mouse, 3 lives, score points, it gets faster, game over screen with a restart button. The video shows the prompt, the agent writing the code, and the finished game running.

## Run it

```sh
node main.ts
```

That builds the game and renders a deterministic 10-second demo (100 frames) into the output directory (`$MAKEFUN_OUTPUT_DIR` or `/output`): `game.html` and `game.js` plus `frames/` and a `manifest.json`. Open `game.html` in any browser to play it yourself. The demo is seeded, so two runs produce byte-identical files.
